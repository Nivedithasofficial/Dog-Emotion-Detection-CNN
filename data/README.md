Dataset: Dog Emotion

Source:
Kaggle - Dog Emotion Dataset
https://www.kaggle.com/datasets/danielshanbalico/dog-emotion

The dataset contains 4,000 images belonging to four classes:

- angry
- happy
- relaxed
- sad

Each class contains approximately 1,000 images.

The dataset is not included in this repository because of its size.
Download the dataset from Kaggle and place/extract it locally before
running the training notebook.
